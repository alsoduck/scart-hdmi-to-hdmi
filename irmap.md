# IR Map for SCART/HDMI to HDMI Converter

| Key         | Value           |
| ----------- | --------------- |
| Protocol    | NEC             |
| Vendor ID   | `0x00`          |
| Hidden Menu | Source + 2580   |

| IR Data     | Function                  |
| ----------- | ------------------------- |
| `02`        | 1                         |
| `03`        | 2                         |
| `04`        | 3                         |
| `05`        | 4                         |
| `06`        | 5                         |
| `07`        | SCART                     |
| `08`        | Resolution (?)            |
| `09`        | HDMI                      |
| `0A`        | 9                         |
| `0C`        | 0                         |
| `0D`        | SCART                     |
| `0F`        | Source / Input            |
| `10`        | OK                        |
| `11`        | Left                      |
| `12`        | Right                     |
| `13`        | Up                        |
| `14`        | Down                      |
| `15`        | Return                    |
| `16`        | Menu                      |
| `18`        | NTSC / PAL                |
| `44`        | Zoom (maybe not working?) |
| `45`        | Power                     |
| `48`        | Volume Up                 |
| `49`        | Volume Down               |
| `5A`        | Resolution (?)            |
| `5B`        | Mute                      |
| `5C`        | 6                         |
| `5D`        | 7                         |
| `5E`        | 8                         |
| `AA`        | Video Mode                |
| `AB`        | PC-RGB                    |
| `AC`        | Freeze                    |
| `C2`        | Unknown                   |
| `C3`        | Audio Mode                |
| `C6`        | Favorite                  |
| `C7`        | Channel List              |
| `D3`        | Favorite List             |
| `D9`        | Menu                      |
| `EA`        | TV                        |
| `EF`        | Sleep                     |
| `F0`        | AV                        |
| `F3`        | Teletext                  |
